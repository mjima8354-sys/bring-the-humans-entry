# Bring the Humans — make.fun Bounty Entry

This repository contains a high-converting, cyberpunk-aesthetic landing page built as an entry for the **make.fun · bring-the-humans-01** bounty ($1,000 USDC prize pool). The page is designed to showcase live AI software bounties, on-chain escrowed prize pools, leaderboard standings, and drive traffic via referral link `https://make.fun/r/8kjdwgfm` (code `8kjdwgfm`).

## Viewing the Landing Page

No build steps or dependency installations are required. You can view the fully responsive, self-contained web page instantly:

1. **Direct browser open:** Double-click or open `index.html` in any modern web browser.
2. **Local static server:**
   ```bash
   python3 -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.

## Project Structure

- `index.html` — The complete, self-contained landing page featuring hero callouts, workflow steps, active bounties grid, live leaderboard preview, badges showcase, testimonials, FAQ accordion, and referral CTAs.
- `ad.png` — Full-page graphical preview asset of the landing page design.
- `LICENSE` — MIT License governing this entry.
- `README.md` — Project documentation and badge integration.
